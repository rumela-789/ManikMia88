# World Watch AI

১০টা AI এজেন্ট প্রতিদিন একবার (২৪ ঘণ্টা পরপর) বিশ্ব রাজনীতি, ব্রেকিং নিউজ, অর্থনীতি,
কূটনীতি, সংঘাত-পরিস্থিতি, প্রযুক্তি, ইতিহাস, ফ্যাক্ট-চেক ও ভবিষ্যৎ প্রবণতা বিশ্লেষণ করে —
এবং একজন "Chief Analyst" এজেন্ট সব একত্র করে একটা দৈনিক কলাম লেখে।

## কীভাবে কাজ করে

```
GitHub Actions (cron, প্রতিদিন ০০:০০ UTC)
        │
        ▼
src/main.py
  ├─ fetch_news.py   → GDELT + RSS থেকে গত ২৪ ঘণ্টার raw ডেটা টানে (ফ্রি, key লাগে না)
  ├─ ৯টা এজেন্ট       → প্রত্যেকে Gemini API-তে কল করে নিজ নিজ বিশ্লেষণ লেখে
  ├─ Chief Analyst    → ৯টা রিপোর্ট একত্র করে ফাইনাল কলাম লেখে
  └─ storage.py       → data/YYYY-MM-DD.json + data/latest.json হিসেবে সেভ করে,
                         GitHub Actions সেটা repo-তে commit করে দেয়
        │
        ▼
frontend/index.html  → data/latest.json পড়ে ব্রাউজারে সুন্দরভাবে দেখায়
```

## সেটআপ (ধাপে ধাপে)

1. এই ফোল্ডারটা একটা নতুন **GitHub পাবলিক রিপোজিটরিতে** পুশ করুন।
2. [Google AI Studio](https://aistudio.google.com) থেকে একটা ফ্রি **Gemini API key** নিন (ক্রেডিট কার্ড লাগে না)।
3. রিপোর তে যান: **Settings → Secrets and variables → Actions → New repository secret**
   - Name: `GEMINI_API_KEY`
   - Value: আপনার key
4. **Settings → Pages** থেকে GitHub Pages চালু করুন (`frontend/` ফোল্ডার সোর্স হিসেবে দিন) — এতে
   ফ্রি একটা ওয়েব ঠিকানা পাবেন যেখানে ডেইলি ব্রিফিং দেখা যাবে।
5. `.github/workflows/daily-agents.yml` এমনিতেই প্রতিদিন চলবে। প্রথমবার টেস্ট করতে
   **Actions ট্যাব → Daily World-Watch Agents → Run workflow** ম্যানুয়ালি ক্লিক করুন।

স্থানীয়ভাবে টেস্ট করতে:
```bash
pip install -r requirements.txt
export GEMINI_API_KEY="your-key-here"
python src/main.py
```

## এটা কতদিন ফ্রি চলবে?

সৎভাবে বললে — **চিরতরে গ্যারান্টি দেওয়া যায় না, কিন্তু বর্তমান লিমিটে ছোট স্কেলে
বছরের পর বছর ফ্রি চালানো বাস্তবসম্মত।** ভাগ করে দেখি:

| উপাদান | ফ্রি টায়ার | আপনার ব্যবহার | টেকসই কিনা |
|---|---|---|---|
| **Gemini API** (লেখা জেনারেশন) | ~১৫০০ রিকোয়েস্ট/দিন, ১৫ RPM (Flash মডেল) | দিনে ~১০ কল (৯ এজেন্ট + ১ চিফ) | ✅ অনেক জায়গা ফাঁকা থাকে |
| **GitHub Actions** (শিডিউলার) | পাবলিক রিপোতে **আনলিমিটেড ফ্রি মিনিট** | দিনে ~২-৩ মিনিট রান | ✅ কোনো সমস্যা নেই |
| **GDELT** (নিউজ ডেটা) | সম্পূর্ণ ফ্রি, রেট লিমিট প্র্যাকটিক্যালি নেই | দিনে ~৫টা কোয়েরি | ✅ নিরাপদ |
| **RSS ফিড** | ফ্রি, পাবলিক | দিনে কয়েকবার | ✅ নিরাপদ |
| **GitHub Pages** (হোস্টিং) | ফ্রি, পাবলিক রিপোর জন্য | স্ট্যাটিক পেজ | ✅ নিরাপদ |
| **স্টোরেজ** | Git রিপো নিজেই (JSON ফাইল) | দিনে ~২০-৫০ KB, **৩০ দিন পর অটো-ডিলিট** | ✅ রিপো কখনো বড় হবে না |

**ঝুঁকি/সীমাবদ্ধতা যা মাথায় রাখা দরকার:**
- Google মাঝেমধ্যে ফ্রি টায়ারের লিমিট **কমায়/পরিবর্তন করে** (২০২৫ ডিসেম্বরে একবার হয়েছিল) —
  তাই লিমিট মাঝেমধ্যে চেক করা ভালো।
- Gemini Pro মডেল ফ্রি টায়ার থেকে বাদ পড়েছে (শুধু Flash/Flash-Lite ফ্রি) — এই প্রজেক্টে
  Flash ব্যবহার করা হয়েছে, যা গুণগত মানে ভালো এবং ফ্রি।
- ফ্রি টায়ারে আপনার প্রম্পট/আউটপুট Google মডেল উন্নয়নে ব্যবহার করতে পারে — স্পর্শকাতর
  কিছু না থাকলে সমস্যা নেই।
- আপনি যদি ইউজার-বেস বড় করেন (হাজার হাজার ভিজিটর, বেশি এজেন্ট, বা ঘণ্টায় ঘণ্টায় আপডেট)
  তখন ফ্রি টায়ার যথেষ্ট হবে না — তখন সামান্য পেইড টায়ারে যেতে হবে (মাসে সম্ভবত $৫-২০)।

**সংক্ষেপে:** বর্তমান ডিজাইন (দিনে ১ বার, ১০টা এজেন্ট) দিয়ে **স্কেল না বাড়ালে কার্যত
অনির্দিষ্টকালের জন্য ফ্রি** চলবে। শুধু গুগলের নীতি পরিবর্তনের দিকে মাঝে মাঝে নজর রাখতে হবে।

## ফোল্ডার স্ট্রাকচার

```
world-watch-ai/
├── agents/personas.py          ১০টা এজেন্টের persona + system prompt
├── src/fetch_news.py           GDELT + RSS থেকে ডেটা সংগ্রহ
├── src/llm_client.py           Gemini API wrapper (retry/backoff সহ)
├── src/storage.py              JSON ফাইলে ফলাফল সেভ
├── src/main.py                 মূল orchestrator script
├── frontend/index.html         ডেইলি ব্রিফিং দেখানোর পেজ
├── .github/workflows/          GitHub Actions cron (২৪ ঘণ্টায় একবার অটো-রান)
├── data/                       জেনারেট হওয়া আর্টিকেল (JSON) — অটো-তৈরি হয়
└── requirements.txt
```
